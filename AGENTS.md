# Project instructions

* This is a dependency-free static website using HTML, CSS, and browser JavaScript. Keep the existing setup unless a request requires changing it.
* Use the browser `Intl` APIs for locale- and time-zone-aware date/time behavior; do not hardcode UTC offsets because daylight-saving rules change.
* Keep changes focused and preserve responsive layouts and accessible semantic markup.
* Document setup and verified run/check commands in `README.md`. Run `node --check app.js` after JavaScript changes.
